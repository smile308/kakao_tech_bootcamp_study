# 학습 부록 목차

> 기존 0~14장이 다루지 않은 부분을 보강한 부록 파일들의 위치와 용도. 메인 학습은 0~14장 순서대로 진행하고, 이해가 부족한 부위를 부록으로 보강한다.

## 부록을 만든 이유

기존 14장은 의도적으로 다음을 스킵했다.

```text
반복되는 DTO
Lombok의 단순 @Getter
CSS와 정적 asset
단순 표시 Component
```

하지만 그 외에 **빠지면 학습 흐름이 끊기는 부분**도 일부 스킵됐다. 이 부록들은 그런 부분을 메운다.


## 의도된 스킵 (이 부록에서도 다루지 않음)

```text
전체 DTO (UserPatchRequestDto, CommentDeleteRequestDto 등 단순 응답/요청)
→ 14장 14.8의 "단순 DTO" 정책에 따라 다루지 않음

Lombok @Getter의 단순 사용법
→ 모든 코드에 흔하므로 별도 학습 가치 없음

CSS, 폰트, SVG
→ 화면 모양만 책임지고 흐름에 참여하지 않음

단순 표시 Component
→ 14장 14.7의 "연결만 확인" 정책에 따라
```
